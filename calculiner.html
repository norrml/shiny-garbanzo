CALCULINER

What Calculiner does (click to fold)
  • Live results. Type any expression and the answer appears greyed out on the same line (=8). Spacing doesn't matter. Each Enter-line is its own calculation, and rows are shaded alternately so you can tell them apart. Long lines use the full box width before wrapping.
  • Operators. + - * × / ÷ ( ) % ! (factorial, whole numbers 0 to 170). Percent is relative: 200+10% = 220, 200-10% = 180, and a lone 50% = 0.5.
  • Dates. Use today, tomorrow, yesterday, or a date written with a month name: 26 oct, 26 oct 2026, oct 26, 26th October (no year = this year). Add or subtract whole days, weeks, months, years: today + 2 weeks, tomorrow - 3 days, today + 1 month, 26 oct + 1 month + 2 days. Results show the weekday (=Mon, 9 Nov 2026). Two dates subtracted give the days between: 25 dec - today = 60 days. Month maths stops at month end (31 Jan + 1 month = 28 Feb). Numeric dates like 26/10/2026 are not supported. Results using today/tomorrow/yesterday change when the day changes. Dates can't be stored in variables.
  • Unfinished input. 39+1+ still shows =40, and open brackets are closed for you.
  • Locking a result. Type =, press Tab, or press Enter. The answer turns blue. Enter also starts a new line, but only if the line has something to calculate (text-only lines just get a new line). Shift+Enter always gives a plain new line. Keep typing an operator after a blue result to continue from that number or date (e.g. today= then + 3 days). Edit anything earlier on the line and the blue results update. Backspace removes the = and its result together. A digit can't be typed straight after a blue result, so use an operator.
  • Variables. Type name=number (e.g. v=1.5) and it turns red. Names are letters only, not case-sensitive, and whole-word: v and vv are different variables. Several can share a line: v=1 ; rr=2 ; dd=4. Variables work on every line, above or below where they're defined. 2v multiplies (=3) and 1+v = 2.5. They also work with dates: n=3 then today + n days. If a name is defined twice, the lowest definition wins. Names containing digits (v99t=3) are treated as comments. A definition must come before any numbers or operators on its line.
  • Variable list. Every detected variable and its value is shown under the box. A name defined more than once is flagged in red with the line that wins. Ignored names (those with digits) appear dimmed.
  • Comments are ignored. Letters, commas and other punctuation are skipped, so rent 500 + food 200 gives 700. Careful: a comment word that matches a defined variable is read as that variable, and a month word next to a number (e.g. mar 5) is read as a date. x is not multiplication; use * or ×.
  • Rounding. Results are rounded to 2 decimals by default (choose 0 to 5). Each blue result carries forward exactly as shown.
  • Commas in results. Off by default. Choose International (1,234,567), Indian (12,34,567) or East Asian (123,4567).
  • Safeguards. Division by zero, overflow, invalid factorials, impossible dates (31 Feb) and malformed lines show no result, so you never see a wrong number.
